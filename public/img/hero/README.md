# Баннеры акций (карусель вверху сайта)

Папка: `public/img/hero/` · картинки для карусели над блоком «Добро пожаловать в Crema Food» (4 слайда, листаются автоматически и стрелками/свайпом).

> **Пока карусель не подключена к картинкам:** сейчас слайды — цветные CSS-градиенты-заглушки (`.hero__carousel-slide--1…4` в `globals.css`, 4 слайда). Когда будут готовы реальные баннеры, их нужно будет подключить в `components/HeroCarousel.tsx` (это отдельная небольшая правка в коде). Имена файлов ниже — договорённость на будущее, а не то, что сайт ищет сейчас.
>
> Этот файл лежит в репозитории и уезжает на продакшен вместе с остальным `public/` (доступен по адресу `/img/hero/README.md`, на сайте не используется). Если нужно держать папку «чистой» — просто удалите README.

## Требования

| | |
|---|---|
| Размер | **2400×1350 px** (компромисс; в идеале для очень широких мониторов — 3840×2160) |
| Пропорции | **16:9** |
| Формат | **JPEG** (`.jpg`), без прозрачности |
| Вес | до **400–500 КБ** на файл (баннер в самом верху страницы — чем легче, тем быстрее первая отрисовка) |
| Имена (на будущее) | `hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg`, `hero-4.jpg` |

## Важно: баннер обрезается — особенно на широких экранах

Карусель растянута на **всю ширину экрана**, а по высоте ограничена: от ≈200 px на телефоне до ≈440 px на большом мониторе. Поэтому картинка 16:9 при показе **обрезается сверху и снизу** — на широком мониторе остаётся лишь узкая горизонтальная полоса (по высоте около **40 %** кадра в центре), на телефоне — почти весь кадр, но чуть обрезается по бокам (≈85 % ширины).

**Главный объект и любой важный элемент — в центральной зоне: примерно по центру по горизонтали (≈70 % ширины) и в середине по вертикали (≈40 % высоты).** Верхняя и нижняя «четверти» кадра на широком экране пропадут — оставляйте там только фон/продолжение композиции.

## Фон под обе темы сайта

Баннер на всю ширину, поэтому под тему он подстраивается меньше (это «обложка», а не карточка), но для единства с остальным сайтом лучше держаться тёплой среднетоновой гаммы: основной фон `#9C8A78` (тёплый таупе), запасной — терракота `#B5754D`. Не использовать чисто белые и чисто чёрные фоны — они «режут» одну из двух тем. Подробности о палитре — в `public/img/items/README.md`.

## Чего не должно быть на баннере

- **Никакого текста, цен, логотипов и рамок на самой картинке:** подписи к слайдам сайт выводит отдельно (и переводит на 3 языка), а картинка с «запечённым» текстом переводиться не будет и может обрезаться на узких экранах.
- Не прозрачный фон и не вырезанные предметы.
