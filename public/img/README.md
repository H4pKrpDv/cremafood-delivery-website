# Изображения сайта (`public/img/`)

Здесь лежат все картинки, которые сайт отдаёт «как есть» (из `public/` — по прямому адресу). Подробные памятки — внутри папок:

| Папка / файл | Что это | Памятка |
|---|---|---|
| `items/` | фото позиций меню (4:3, 800×600, JPEG) | `items/README.md` |
| `categories/` | баннеры подкатегорий меню (16:9, 1600×900, JPEG) | `categories/README.md` |
| `hero/` | баннеры акций вверху сайта (16:9, 2400×1350, JPEG) — **пока не подключены в коде** | `hero/README.md` |
| `og_default.png` | картинка-превью при отправке ссылки в соцсети и мессенджеры | ниже |
| `logo.png` | логотип в шапке и футере | ниже |

> Эти README лежат в репозитории и уезжают на продакшен вместе с остальным `public/` (доступны по адресам вида `/img/items/README.md`, на сайте не используются). Если нужно держать папки «чистыми» — их можно просто удалить, на работу сайта это не повлияет.

## Превью для соцсетей — `og_default.png`

Показывается, когда ссылку на сайт отправляют в Telegram, WhatsApp, Viber, Facebook и т.п. (адрес прописан в `src/lib/seo.ts`).

| | |
|---|---|
| Размер | **1200×630 px** (пропорция ≈1.91:1 — стандарт Open Graph) |
| Формат | **PNG** (имя файла **строго `og_default.png`**; если захотите JPEG — потребуется поменять путь в `src/lib/seo.ts`). **Не WebP** — часть площадок не показывает WebP-превью |
| Вес | до **300 КБ** |
| Файл лежит | прямо в `public/img/` (не в подпапке) |

Здесь, в отличие от баннеров меню, **текст и логотип на картинке допустимы и даже желательны** (название «Crema Food», слоган) — это превью-карточка, а не часть страницы. Главное держать важное в **центре кадра** (примерно квадрат 630×630 по центру): некоторые мессенджеры обрезают превью по бокам.

Превью не зависит от тёмной/светлой темы сайта — выбирайте фон по айдентике бренда (можно взять тот же тёплый таупе `#9C8A78`).

После замены файла превью в мессенджерах обновляется не сразу — они кэшируют картинку (в Telegram помогает отправить ссылку боту `@WebpageBot`).

## Логотип — `logo.png`

Круглый логотип (на собственном тёмном круге с золотой графикой) — одинаково смотрится на светлой и тёмной теме, отдельная версия под тему не нужна. Отображается в шапке и футере небольшим (в шапке ≈34 px); если нужно заменить — квадратный PNG от 200×200 px (лучше 400×400 для Retina). Иконка вкладки браузера (favicon) — отдельные файлы `src/app/icon.png` и `src/app/favicon.ico`, этой папки не касается.
