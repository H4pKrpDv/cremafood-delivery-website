# Баннеры подкатегорий меню

Папка: `public/img/categories/` · большая картинка-баннер над сеткой позиций каждой подкатегории («Кофе», «Чай», «Завтраки» и т.д.).

> Этот файл лежит в репозитории и уезжает на продакшен вместе с остальным `public/` (доступен по адресу `/img/categories/README.md`, на сайте не используется). Если нужно держать папку «чистой» — просто удалите README, на работу сайта это не повлияет.

## Требования

| | |
|---|---|
| Размер | **не менее 1600×900 px** |
| Пропорции | **16:9** (горизонтальный кадр) |
| Формат | **JPEG** (`.jpg`), без прозрачности |
| Вес | до **250–350 КБ** на файл (JPEG, качество ≈80–85) |
| Имя файла | **строго как в списке ниже** |

## Важно: баннер обрезается по-разному на разных экранах

- На телефоне и планшете (до 768 px) баннер показывается **целиком, 16:9** на всю ширину.
- На ноутбуке и десктопе (от 769 px) тот же файл показывается рядом с текстом **в пропорции 4:3**, то есть **обрезается слева и справа** (остаются центральные ≈75 % ширины).

Поэтому главный объект (блюдо, напиток, надпись на стекле и т.п.) держим **строго в центральной части кадра — в зоне 1200×900 px из 1600×900**. Всё, что ближе к левому и правому краю, на десктопе пропадёт.

## Фон под обе темы сайта

Тот же принцип, что и для фото позиций: среднетоновый тёплый фон, единый для всех баннеров, чтобы одинаково смотрелись на светлой и тёмной теме.

| Вариант | Hex | Когда использовать |
|---|---|---|
| **Тёплый таупе — основной** | `#9C8A78` | Фон для всего меню по умолчанию. Одинаково чётко читается и на светлой, и на тёмной теме сайта |
| Терракота / глина | `#B5754D` | Запасной вариант для части позиций (например кофе и десерты) — но тогда держите единый стиль внутри группы |
| Ореховое дерево | `#8B6B4A` | Уютно, но на тёмной теме уже ближе к фону карточки |
| Тёплый серый камень | `#B8AFA4` | Нейтральный; на светлой теме отличается от карточки слабовато |
| Шалфей (зелёно-серый) | `#A3A58A` | Акцент для лимонадов/завтраков, выбивается из коричневой палитры |

Это ориентир по ТОНУ и средней яркости, а не точный цвет заливки: живой фон (дерево, камень, лён, мягкий свет) — нормально и даже лучше ровной краски.

**Не использовать:** чисто белый и очень светлые фоны (например овсяный `#E3D3B8`) — на светлой теме фото растворяется в карточке; чёрный и очень тёмные (например мокко `#6B4F3A`) — на тёмной теме фото проваливается.

## Чего не должно быть на баннере

- **Никакого текста, цен, логотипов и рамок на самой картинке** — название и описание подкатегории выводятся сайтом отдельно и переводятся на 3 языка, а текст «запечённый» в картинку перевести нельзя.
- Не прозрачный фон и не вырезанные предметы.

## Как проверить, что фото подхватилось

1. Положить файл в эту папку **с точным именем** из списка.
2. **Перезапустить** `npm run dev` (список имеющихся фото собирается при запуске/сборке — `scripts/generate-image-manifest.mjs`).
3. Открыть сайт в обеих темах и на узком (мобильном) и широком экране.
