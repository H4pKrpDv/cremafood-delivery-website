# Фото соусов и добавок (модификаторов)

Эти картинки показываются в карточках соусов на странице позиции (кнопки
«Добавить» у соусов). Пока файла нет — вместо него автоматически рисуется
заглушка (так же, как у позиций меню).

## Как назвать файл

`<id модификатора>.jpg` — id берётся из `src/data/menu.json` →
`modifierGroups` (и ключа `modifiers.<id>.name` в `src/data/i18n/*.json`).

Сейчас нужен один файл:

- `ketchup.jpg` — Кетчуп

## Требования

- Формат: JPG (допустимы также PNG/WebP/AVIF, но тогда нужно поменять
  расширение в `modifierImagePath()` в `src/components/ItemPage.tsx`).
- Пропорции 4:3 (например, 800×600), предмет по центру — карточка
  показывается маленькой, мелкие детали не видны.
- Вес — до ~100 КБ.

После добавления файла перезапустите `npm run dev`/`build` — манифест
картинок (`src/data/imageManifest.json`) пересоберётся сам
(`scripts/generate-image-manifest.mjs`).
