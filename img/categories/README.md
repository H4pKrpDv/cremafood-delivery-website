# img/categories/ — баннеры подкатегорий меню

Сюда кладутся фото-баннеры подкатегорий меню (13 шт. — по одному на
каждую подкатегорию с товарами; пустые подкатегории без товаров баннер
не показывают вообще, см. Context.md).

**Важно про имена файлов:** так же, как и в `img/items/` — сейчас
`data/menu.json` ссылается на баннеры с расширением `.jpg`. Просто
положите сюда файлы с именами ниже — сайт подхватит их сам при
пересборке (`node build/build.js`). Если захотите сразу `.webp` —
дайте знать, обновлю расширения в `data/menu.json` одной правкой.

Требования к баннерам (см. Context.md):
- Соотношение сторон: **4:3** на десктопе / **16:9** на мобильном
  (адаптируется через CSS `aspect-ratio`, один и тот же файл на оба
  брейкпоинта — кроп делает браузер, отдельных версий под мобильный/
  десктоп готовить не нужно)
- Минимум 800×600px
- Целевой вес после сжатия — до ~200KB
