# img/ — статические изображения сайта

- **`logo.png`** — уже на месте. Реальный логотип (круглая золотая
  эмблема, прозрачный фон), обрезан в круг по кольцу на исходном
  изображении заказчика. Используется и как favicon (`<link rel="icon">`
  в `<head>`), и как `.logo__mark` в шапке/футере — один файл на обе
  роли.
- **`items/`** — фото карточек товара в сетке меню (49 шт., 4:3). Список
  ожидаемых имён файлов и требования к формату — см. `items/README.md`.
- **`categories/`** — баннеры подкатегорий меню (13 шт., 4:3/16:9). Список
  ожидаемых имён файлов и требования к формату — см. `categories/README.md`.
- **`og_default.png`** — пока отсутствует, нужно добавить. Используется
  как превью страницы при шаринге ссылки в соцсетях/мессенджерах
  (`og:image`/`twitter:image`, а также `image` в JSON-LD). Рекомендуемый
  размер — 1200×630px (стандарт Open Graph), с логотипом/фирменным
  стилем Crema Food, т.к. это первое, что видят люди при пересылке
  ссылки на сайт.

Когда появятся реальные фото для hero-карусели (сейчас там CSS-градиенты-
заглушки, см. комментарий в `build/template.html` над `.hero__carousel`)
— под них тоже понадобится отдельная папка (например `img/hero/`), но
пока структура под неё не создавалась: в самой разметке сайта ещё нет
`<img>`-ссылок на такие файлы (только на будущее, см. Context.md).

После добавления любых файлов сюда — пересобери сайт: `node build/build.js`.
